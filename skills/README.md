# Skills

可复用能力包，每个 skill 提供特定任务的标准化流程。

## 当前 Skills

| Skill | 用途 |
|---|---|
| `quality-gate` | 代码变更后运行质量门禁 |
| `ai-change-guard` | AI 变更安全检查 |
| `github-pr-ci` | PR 创建与 CI 管理 |
| `tauri-debug` | Tauri 客户端调试 |
| `html-to-tauri-client` | HTML 原型转 Tauri + React 代码 |
| `ui-visual-review` | UI 截图视觉评审 |
| `cloudflare-deploy` | Cloudflare Workers 部署 |

## 使用规则

当任务属于某个 skill 覆盖范围时，Agent 必须先读对应 `SKILL.md`。

Skill 不覆盖项目规则。Skill 是任务流程，`CLAUDE.md / AGENTS.md` 仍然是最高约束。
